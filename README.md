# Clock Learning

Clock Learning is a web app I’m building to help children learn how to read an analog clock.

The app uses a large interactive clock to explain the hour, minute and second hands. Children can enter a time, see the clock update, and learn different ways to say that time.

## Features in the first version

- Large SVG analog clock with hour, minute and second hands.
- Time input for hours, minutes and seconds.
- Digital time display.
- Multiple written ways to read a selected time.
- Boy and girl colour themes.
- Show or hide hour numbers, minute numbers, 24-hour numbers, labels, minute guides, markings and individual hands.
- Beginner, Intermediate, Advanced, Challenge and Custom display settings.
- Random time generator.

The clock face is inspired by a teaching clock reference, with a 1–60 minute scale, 1–12 hour numbers, a 13–24 ring, and Past / To labels.

## Technology

- React
- Vite
- JavaScript
- CSS
- SVG

The app runs in the browser and does not need a backend, database or paid API.

## Run locally

1. Install Node.js.
2. Clone this repository.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown by Vite.

## Build

Run `npm run build` to create the production files in the `dist` folder.

## Deployment
